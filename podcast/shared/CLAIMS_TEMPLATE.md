# Claim Ledger Template

One claim ledger per episode, stored next to the script as `claims.md`. Every factual
claim the hosts say must appear here with a source. No source, no airtime.

Format (copy this table; one row per claim):

```
# <Episode> — Claim Ledger
Verification date: YYYY-MM-DD. Verdicts: keep / qualify / correct / remove.

| # | Claim as scripted | Source | Verdict |
|---|---|---|---|
| 1 | <exact wording or close paraphrase> | <URL> (<what the source is, who publishes it>) | keep |
```

## Rules

- **Exact URL per row**, verified on the verification date. "Google it" is not a source.
- Prefer primary sources: official sites, government/ordinance text, the organizer's own
  listing, the study or dataset itself. Secondary reporting is allowed only when the
  primary is paywalled or unavailable — then say so in the source note.
- Attribute narrowly: if the organizer's listing confirms time and location but not
  price, the ledger says so and the script may not claim a price.
- Verdicts: `keep` (verified as scripted), `qualify` (true only with the qualifier —
  the qualifier must be in the script), `correct` (script was wrong; fix recorded),
  `remove` (cut; do not reintroduce without new sources).
- After any correction, add a section: `## Corrected in audio YYYY-MM-DD` with the
  old wording, the new wording, and why — same as the published record.
- Removed claims get a `## Removed` section so nobody reintroduces them.

## Hard lessons (learned on OC Pack Ep 1, 2026-09-26)

- "Free" is a claim: an event listing that confirms time/location but never says "free"
  does not support "a free event."
- Absolute guarantees ("every single time") need absolute sources. They never have one.
  Qualify: "as long as it's registered."
- Dates and weekdays must be checked against a calendar (Oct 11 2026 is a Sunday).
