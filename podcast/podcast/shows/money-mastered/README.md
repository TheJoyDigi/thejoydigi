# Money, Mastered

Production sources for the Money, Mastered show. The show bible is `SHOW.md`.

- **Served output (what listeners get):** `public/podcasts/money-mastered/` — final
  chapter MP3s, `feed.xml`, cover art. Written only by the publish step.
- **Production sources (what lives here):** chapter scripts, claim ledgers, and notes
  under `chapters/` as episodes are produced.

Chapters follow the book curriculum strictly. Audio standard: -16 LUFS / 128 kbps.
