# Worth It — a Value, Created short series (Lola's version)

**Working title:** Worth It. **Tagline:** *See the value. Be the value.*
**Format:** ~30-second vertical shorts. One everyday transaction per episode.
**Voice:** one warm, direct narrator. **Format:** anime, with one recurring lead who emotes while the narrator talks.

## Why this instead of Trap or Treasure

Trap or Treasure is well-built, but its frame is **defensive**: the system is full
of traps, don't step in them, here's the escape. The viewer is a potential
*victim* who needs protection. It teaches loss avoidance.

Value, Created is an **offensive** philosophy: every value starts as a problem
solved; price is a rumor about value; creating isn't enough, you must capture;
give value first. The viewer should be a potential *creator*.

A show that only teaches people to dodge traps never teaches them the actual
game — which is seeing where value lives, creating it, and standing on the
side of the counter that gets paid. That's what this series is: the book's
thesis, one everyday moment at a time.

## The episode arc (every episode, 30 seconds)

```
THE MYTH    the common advice everyone repeats          (pattern interrupt)
THE REFRAME where the value actually was                (see it)
THE FLIP    the better question                         (the turn)
THE MOVE    one action                                  (do it)
SIGN-OFF    "Worth it."                                 (the verdict)
```

| Beat | Book chapter it dramatizes |

| The price is not the value | Ch 4 — Price Is Not Value |
| Every value starts as a problem solved | Ch 6 — the one-sentence theory of the whole book |
| Stop optimizing the buy side; get on the capture side | Ch 15 — Creating Isn't Enough |
| The move is always a small act of creation or giving | Ch 28 — Give Value First |
